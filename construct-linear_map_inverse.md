# linear map inverse

* Given a [[construct-linear_map|linear map]] $f:V\to W$ over a field $\mathbb F$, a linear map $g:W\to V$ over the same field is an **inverse linear map** of $f$ if it is an [[construct-function_inverse|inverse function]] of $f$. Thus $g\circ f=\operatorname{id}_V$ and $f\circ g=\operatorname{id}_W$.
