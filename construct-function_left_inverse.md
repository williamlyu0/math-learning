# function left inverse

* Given a [[construct-function|function]] $f:X\to Y$, a function $g:Y\to X$ is a **left inverse** of $f$ if their [[construct-function_composition|composition]] satisfies
  - $g\circ f=\operatorname{id}_X$.

  * INTERPRETATION:
    * Applying $f$ and then $g$ recovers every input in $X$.
