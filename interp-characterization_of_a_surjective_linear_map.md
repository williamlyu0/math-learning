# INTERP: characterization of a surjective linear map

* A [[construct-linear_map|linear map]] $f:V\to W$ between finitely generated vector spaces is [[construct-surjective_linear_map|surjective]] if and only if
  - $\operatorname{rank}(f)=\dim W$.

  * EXPANSION:
    * The image is a subspace of $W$, and [[construct-rank|rank]] is its dimension. If $f$ is surjective, the image is $W$, so the dimensions agree.

    * Conversely, a subspace of a finite-dimensional vector space with the same dimension as the whole space is the whole space. Hence if $\operatorname{rank}(f)=\dim W$, the image is $W$ and $f$ is surjective.
