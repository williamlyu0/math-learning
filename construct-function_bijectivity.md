# function bijectivity

* A [[construct-function|function]] $f:X\to Y$ is **bijective** if every $y\in Y$ has exactly one preimage in $X$.
  * EXPANSION: exactly one preimage
    * For each $y\in Y$, there exists an $x\in X$ such that $f(x)=y$, and every $x'\in X$ satisfying $f(x')=y$ must equal that $x$.
