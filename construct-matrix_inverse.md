# matrix inverse

* Given an $n\times n$ [[construct-matrix|matrix]] $A$ over $\mathbb F$, an $n\times n$ matrix $B$ over $\mathbb F$ is an **inverse** of $A$ if both [[construct-matrix_multiplication_matrix_product|matrix products]] satisfy $AB=BA=I_n$, where $I_n$ is the matrix with $1$ on the main diagonal and $0$ elsewhere. A matrix $A$ is **invertible** if such a $B$ exists.
