# system of linear equations

* A finite **system of linear equations** over a [[construct-field|field]] $\mathbb F$ consists of finitely many equations in finitely many unknowns. Each equation has the form
  - $a_1x_1+\cdots+a_nx_n=b$, where $a_1,\ldots,a_n,b\in\mathbb F$.

  * INTERPRETATION:
    * The system is **homogeneous** when every right-hand constant is zero.
