# function injectivity

* A [[construct-function|function]] $f:X\to Y$ is **injective** if, for all $x_1,x_2\in X$:
  - $f(x_1)=f(x_2)$ implies $x_1=x_2$.

  * INTERPRETATION:
    * Distinct inputs have distinct outputs: the output does not lose the distinction between inputs.
    * If $X$ is empty, the condition holds vacuously.
