# linear independence

* Vectors $v_1,\ldots,v_n$ are **linearly independent** if the only coefficients for which their [[construct-linear_combination|linear combination]] is $0_V$ are $a_1=\cdots=a_n=0_{\mathbb F}$.

  * INTERPRETATION:
    * A collection that is not linearly independent is **linearly dependent**.
    * The empty collection is linearly independent.
