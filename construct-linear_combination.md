# linear combination

* Given vectors $v_1,\ldots,v_n$ in a [[construct-vector_space|vector space]] $V$ over $\mathbb F$ and scalars $a_1,\ldots,a_n\in\mathbb F$, their **linear combination** is
  - $a_1v_1+\cdots+a_nv_n$.

  * INTERPRETATION:
    * The empty linear combination is $0_V$.
