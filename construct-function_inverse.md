# function inverse

* A [[construct-function|function]] $f:X\to Y$ is **invertible** if there is a function $g:Y\to X$ that is both a [[construct-function_left_inverse|left inverse]] and a [[construct-function_right_inverse|right inverse]] of $f$:
  - $g\circ f=\operatorname{id}_X$.
  - $f\circ g=\operatorname{id}_Y$.

  Such a function $g$ is called an **inverse function** of $f$.
