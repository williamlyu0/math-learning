# function right inverse

* Given a [[construct-function|function]] $f:X\to Y$, a function $h:Y\to X$ is a **right inverse** of $f$ if their [[construct-function_composition|composition]] satisfies
  - $f\circ h=\operatorname{id}_Y$.

  * INTERPRETATION:
    * For every $y\in Y$, the function $h$ selects an input that $f$ maps to $y$.
