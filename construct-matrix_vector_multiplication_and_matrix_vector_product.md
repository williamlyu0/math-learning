# matrix vector multiplication and matrix vector product

* Given a [[construct-matrix|matrix]] $A$ with columns $A_1,\ldots,A_n$ and a scalar tuple $x=(x_1,\ldots,x_n)$, define their **matrix–vector product** as the [[construct-linear_combination|linear combination]]
  - $Ax=x_1A_1+\cdots+x_nA_n$.

  * INTERPRETATION:
    * Each column is a tuple, regarded here as a vector with componentwise operations. The components of $x$ supply the coefficients.
